## 任务

1. **启用 Pi 会话持久化**：产品路径以 `--session-dir` 指向应用数据目录运行（`--no-session` 仅限测试）；设置 `PI_CODING_AGENT_DIR` 指向应用专属 Pi 配置（§7.2）。应用数据根用 `%LocalAppData%\Fufucode`，目录布局按计划 §7.2。
2. **会话恢复**：用 `get_entries`（`since` 游标）从会话文件重建时间线，含压缩前历史；重连时先重建状态再接收新工作（§7.2）。进程中断的任务显示为 Interrupted，**不自动重发**最后的 prompt 或工具调用（§7.2、验证项 C03）。
3. **桌面元数据库**：SQLite 存项目（规范化绝对路径 + 稳定 ID，§7.3）、会话索引、草稿、偏好；带版本迁移与修改前备份。铁律：只存元数据与可重建缓存，**不做第二份对话历史**（§7.2）。
4. **独占所有权**：同一会话文件不得同时交给多个可写进程；启动/恢复时做所有权检查（§7.3）。
5. **测试**：FakePi 会话 fixture 覆盖恢复路径；真实 Pi 持久化冒烟；真实模型一轮对话 → 关闭 → 重开恢复（计划 M4 完成条件的 Core 部分，有凭据时执行）。
