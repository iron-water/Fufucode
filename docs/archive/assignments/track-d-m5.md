1. **用户反馈修复**：F06——Enter 误吞（ImeEnterGuard 启发式过激；rime 用户也必须顺滑）；F05——停止后显示中性"已中断"而非红色错误（Core 侧分类映射 A 已修，`fa9cfe9`，你接 UI 呈现）；F04——排队状态指示（用户必须能分辨"已排队"与"运行中"；当前运行中提交一律 FollowUp 排队且无提示）；F02——两条编译警告清零（CS0618、AVLN3001）。
2. **F09 视觉升级**：以 UniGetUI 为艺术基准完成视觉基座换代——完整 Fluent 令牌字典（Light/Dark）、层次与间距体系、图标体系、动效克制而精致；允许引入必要的 NuGet 资产（图标库等），记录来源与理由。检验标准：用户下次打开能立刻感到"换了一个档次"，且你自己愿意长期使用。
