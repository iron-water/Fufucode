# Fufucode 前端能力分级与生命周期演进开发守则

**版本**：2026-10-20 权威基线  
**制定依据**：依据用户 2026-10-19 至 2026-10-20 核心指示，确立前端能力的物理承载形态、7 级动态能力梯队、功能生命周期演化模型，以及小功能的**三大藏点体系**。

---

## 一、 基础物理承载形态（Physical UI Surfaces）

在桌面前端界面中，所有功能在物理展现上由大到小分为 5 个物理承载层级：

1. **全屏独立 (Full Page)**：脱离主对话与工作区，拥有独立左侧导航、分类子页与完整面包屑（如设置）。
2. **侧边栏 (Dock / Sidebar)**：拥有左、右、底三通用停靠区的 Tab 席位，承载视口重型或独立交互流程（如浏览器、终端、文件管理）。
3. **独立 UI (Standalone UI / Modal / Inline)**：具备专门为之定制的轻量级界面，表现为居中弹窗、下拉抽屉、浮动面板或对话流内嵌控件（如命令面板、通知中心、会话刻度）。
4. **显示按钮 (Capsule Quick Actions)**：在顶栏左右浮动胶囊条内直接外露的极高频单步点击图标（如前进、后退、新建、侧栏开关、搜索、设置）。
5. **小功能藏点 (Housing Spots for Small Functions)**：小功能的收纳与栖息之所，包括**三大专属藏点**（左右辅助栏、顶部动态岛、底部状态栏）。

---

## 二、 小功能的三大藏点体系（The Three Hiding Spots）

小功能并不是简单粗暴地丢弃，而是根据其**上下文关联性**与**呼出频次**，分布在三大互补的藏点中：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [左胶囊] ───▶ [ ﹀ 左辅助栏 ]          【顶部动态岛】        [ ⋯ 右辅助栏 ] ◀─── [右胶囊]
│ (高频会话/项目子菜单)              (会话活态与快捷磁贴)      (低频工具/诊断子菜单)
├────────────────────────────────────────────────────────────────────────┤
│                               主工作区                                  │
├────────────────────────────────────────────────────────────────────────┤
│ 【底部状态栏】(默认不展示，被动细条：连接/Shell/活动/Token/用时)               │
└────────────────────────────────────────────────────────────────────────┘
```

| 藏点序号 | 藏点名称 | 物理位置与呈现形态 | 专职定位与承载内容 | 默认状态 |
|:---:|---|---|---|:---:|
| **藏点 ①** | **左右辅助栏**<br>*(Auxiliary Bars)* | 顶栏左胶囊尾部（`[ ﹀ ]`）与右胶囊尾部（`[ ⋯ ]`）的下拉二级子菜单。 | **全局命令与功能库**：<br>• **左辅助**：高频常用，收将会话管理、快捷复制、导出、分叉、项目、工作区页面。<br>• **右辅助**：低频重度，收纳文本编辑、视图与布局、语音朗读、系统诊断与监控、帮助与全局。 | **常驻外露入口**<br>(点击呼出菜单) |
| **藏点 ②** | **顶部动态岛**<br>*(Top Dynamic Island / Session Island)* | 顶栏正中央的灵动交互胶囊（呼吸圆点 + 会话标题 + 运行状态 + 耗时 + 卫星排队点）。 | **当前会话的上下文活态与快捷磁贴**：<br>• 常态：紧凑展示当前会话名、运行活动与用时，不占地。<br>• 展开（点击岛）：弹出浮动面板，承载与当前会话强绑定的**核心操作磁贴**（会话重命名、置顶、分叉、分享、计划任务）与**即时干预操作**（停止、引导）。支持通过 `UiActionPosition.SessionIsland` 配置。 | **常态紧凑弱化**<br>(点击展开磁贴面板) |
| **藏点 ③** | **底部状态栏**<br>*(Bottom Status Bar)* | 窗口最底部的单行发丝细条（约 26px 高）。 | **底层被动运行指标**：<br>连接状态、Shell 连接、会话活动状态、实时 Token 计数、本轮回合耗时、项目与 Git 分支。纯文本展示，不承载复杂按钮交互。 | **默认不展示**<br>(外观排布中可开启) |

## 三、 七级动态能力梯队（The 7-Tier Capability Matrix）

为适应功能在开发周期中**从小到大孵化、从大到小精简、合并与升降级**的生命周期演进，前端细分为 7 级动态能力梯队：

```text
a. 超强 (Ultra)      ── 全屏独立大页面 (当前: 设置; 未来候选: 自动开发独立工作台)
b. 最强 (Max)        ── 核心独立侧边栏 (浏览器, 终端, 文件管理, 会话管理, 自动开发[暂], 侧边聊天)
c. 极高 (XHigh)      ── [动态中间态/待裁撤合并] 次级侧边栏 (本地审查, 资料库, 变更, 性能[孵化中])
d. 很高 (High)       ── [动态中间态/升级中] 原独立UI逐步提供侧边栏停靠 (通知中心, 用量详情)
e. 中等 (Medium)     ── 专属独立轻量 UI / 弹窗 / 浮层 (命令面板, 会话刻度, 关于 Fufucode)
f. 较弱 (Low)        ── 顶栏左右胶囊常驻外露快捷按钮 (4+5个常用操作)
g. 最弱 (Minimal)    ── 三大藏点收纳动作与底层信息 (左右辅助栏子菜单、动态岛磁贴、状态栏细条)
```

| 级别 | 梯队标识 | 定位与形态 | 动态特征与演进方向 | 代表功能项 |
|:---:|:---:|---|---|---|
| **a** | **超强 (Ultra)** | **全屏独立页面** | 系统最重级。未来自动开发可能独立建页。 | 设置 (`settings`) |
| **b** | **最强 (Max)** | **核心独立侧边栏** | 拥有固定侧边栏席位、复杂状态流与完整视口。 | 浏览器 (`browser`)、终端 (`terminal`)、文件管理 (`files`)、会话管理 (`overview`)、自动开发 (`automation` 现阶段)、侧边聊天 (`sidechat`) |
| **c** | **极高 (XHigh)** | **次级独立侧边栏** | **【动态中间态】** 占有侧边栏席位，但功能较聚焦；可能在未来开发中合并、收归或撤销。 | 本地审查 (`local-review`)、资料库 (`library`)、变更 (`changes`)、性能中心 (`performance` 孵化中) |
| **d** | **很高 (High)** | **可停靠的独立 UI** | **【动态中间态】** 最初为独立 UI，随演进逐步提供停靠侧边栏能力。 | 通知中心 (`notifications`)、用量详情 (`usage`) |
| **e** | **中等 (Medium)** | **专属独立轻量 UI** | 不占侧边栏，但有专属定制弹层或内嵌控件。 | 命令面板 (`commands`)、会话刻度 (`MessageRuler`)、关于 (`help.about`) |
| **f** | **较弱 (Low)** | **顶栏胶囊显式按钮** | 体量极小，但因极高频使用而常驻外露在左右胶囊。 | 前进、后退、新建会话、左/右/底栏开关、搜索、通知、设置 |
| **g** | **最弱 (Minimal)** | **三大藏点收纳** | 最细粒度动作或监控数据，收纳进三大藏点。 | 会话动作、快捷复制、文本编辑、视图缩放、底层排错、动态岛磁贴、状态栏细条 |

## 四、 功能生命周期演变法则（Functional Morphing Law）

所有功能不是静态固化的，必须遵循动态演进规律：

1. **底层功能的向上孵化**：
   * 例如 `help.performance`（性能跟踪）、`help.tasks`（运行状态与资源）、`trace`（调用轨迹）最初散落在 Minimal 级；现阶段在右辅助栏归拢孵化，正在打包整合成 c 级（XHigh）的“性能中心”侧边栏，未来成熟后甚至可能晋升为 b 级（Max）。
2. **中间态功能的动态裁撤与合并**：
   * c 级（XHigh）功能（如本地审查、资料库、变更）当前占有独立侧边栏席位；后续可根据紧凑度要求，随时降级或合并（如 Git 变更与本地审查合并为统一审查面板）。
3. **独立 UI 的侧栏化迁移**：
   * d 级（High）功能（如通知中心、用量详情）最初纯属 e 级弹窗，现支持侧边栏停靠，具备双重形态。

## 五、 顶栏胶囊与辅助栏的详细收纳架构

### 1. 顶栏悬浮胶囊栏（Capsule Quick Actions，Low 级）
* **左胶囊**：`[ ◫ 左侧栏开关 ] [ ← 后退 ] [ → 前进 ] [ + 新聊天 ]` + `[ ﹀ 左辅助功能 ]`
* **右胶囊**：`[ 🔍 搜索面板 ] [ ⬒ 底栏开关 ] [ ◧ 右侧栏开关 ] [ 🔔 通知中心 ] [ ⚙ 设置入口 ]` + `[ ⋯ 右辅助功能 ]`

### 2. 左辅助栏（﹀ 菜单，Minimal 级）：高频常用、项目与会话
定位为**轻量、敏捷的日常工程与会话控制台**，禁止零散平铺，严格收纳为 6 个带图标的二级子菜单：
* **💬 会话管理** (`session.*`)：会话内查找（默认项）、重命名、上一个/下一个会话、置顶、标为未读、归档、已归档。
* **📋 复制** (`copy.*`)：复制会话 ID（双击默认项）、复制为 Markdown、复制工作目录、复制会话路径、复制项目路径、复制日志。
* **📁 项目** (`project.*`)：打开文件夹、在资源管理器中打开、打开方式、资料库。
* **📥 导出** (`session.export.*`)：导出为 Markdown（双击默认项）、导出元数据、导出为 PDF。
* **🔀 分叉** (`session.fork.*`)：分叉（双击默认项）、在新工作树中创建分支。
* **🗂️ 工作区页面**：返回对话、文件、变更、内置浏览器、交互终端、扩展。

### 3. 右辅助栏（⋯ 菜单，Minimal 级）：低频重度、工具、视图与系统维护
定位为**全局工具、视图排布与底层排错中心**，严格收纳为 5 个带图标的二级子菜单：
* **✏️ 编辑** (`edit.*`)：撤销（双击默认项）、重做、剪切、复制、粘贴、删除选中文字、全选。
* **🖥️ 视图与布局** (`view.*`, 布局重置)：切换全屏（双击默认项）、放大、缩小、实际大小、恢复默认布局、显示/隐藏输入区、变更摘要开关。
* **🔊 语音朗读** (`speech.*`)：开始朗读（双击默认项）、停止朗读、暂停朗读、继续朗读、朗读设置。
* **🩺 诊断与系统** (`trace`, 诊断包, 自动开发, 本地审查, 性能孵化项)：查看调用轨迹（双击默认项）、自动开发、本地审查、运行状态与资源监控、故障排除、系统状态、开始/结束性能跟踪、导出完整诊断包。
* **ℹ️ 帮助与全局** (`help.*`, 全局操作)：关于 Fufucode（双击默认项）、键盘快捷键、检查更新、模型认证管理、新建独立窗口。

## 六、 硬性开发约束

1. **全员矢量图标**：所有功能项在 `WorkbenchActionDefaults.Icon` 中必须有明确的 Fluent 语义图标，禁止回退无意义占位符。
2. **统一子菜单收纳**：辅助栏严禁添加顶级平铺散项；新动作必须归入对应子菜单，或在孵化升级时提升至相应能级。
3. **三大藏点按需分流**：
   - 会话绑定的即时操作磁贴与活态指示 → 进入**顶部动态岛**；
   - 被动运行指标数据 → 进入**底部状态栏**（默认隐藏）；
   - 分类命令动作与全局工具 → 进入**左右辅助栏二级子菜单**。
4. **用户自定义保留**：无论默认归属如何优化，“设置 → 外观 → 前端功能排布 → 辅助栏”中的三选自定义（左辅助/右辅助/不显示）始终为最高优先级覆盖。
