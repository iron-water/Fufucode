# FUFU 桌面宠物（Fufucode Desktop Pet）产品与技术规格书

**版本**：2026-10-21 权威基线  
**定位**：Fufucode CLI 与 Agent 的拟人具象化实体，具备独立生命周期、独立系统托盘、生动交互与丰富情绪系统的桌面伴侣。

---

## 一、 用户核心定调与核心决策

依据用户 2026-10-21 明确要求，FUFU 桌宠确立以下四大核心支柱：

| 维度 | 决策方案 | 决策依据与体验特征 |
|---|---|---|
| **物理与停靠** | **自由拖拽悬浮** | 无重力下落与窗体遮挡约束；用户可拖拽到屏幕任意角落（如右下角、辅屏边角），支持始终置顶或置底，最小化对日常编码的打扰。 |
| **生命周期** | **独立微进程 + 专属托盘** | 独立于 Fufucode 主窗口，甚至在主窗口未启动时也能单独常驻；托盘区有专属宠物图标与菜单；通过轻量 IPC（NamedPipe）接收主程序/CLI 的 Agent 状态。 |
| **美术与动画** | **AI 单图 + 程序化形变管线** | 针对“创作者只有 AI 生成图与简单动作”量身定制：以 AI 静态关键图为底图，叠加 Avalonia 程序化弹性呼吸、果冻拉伸、表情贴花与粒子动效，低成本实现丝滑灵动。 |
| **交互深度** | **全方位丰富交互** | 不止是冷冰冰的状态反射：包含戳戳乐、摸头悬停、拖拽挣扎、作息时间感知、拖拽文件投喂执行，以及与 CLI 编程深度共情的情绪系统。 |

## 二、 架构与生命周期模型

### 2.1 双进程架构

```text
┌─────────────────────────────────┐       ┌─────────────────────────────────┐
│     Fufucode 主程序 / CLI        │       │    FUFU 桌宠 (Fufucode.Pet)      │
│  (Fufucode.App / fufucode.exe)  │       │      (独立轻量级 Avalonia 进程)   │
├─────────────────────────────────┤       ├─────────────────────────────────┤
│ • 完整代码编辑器、浏览器、终端      │       │ • 透明无边框穿透悬浮窗             │
│ • 主系统托盘图标 (Main Tray)      │       │ • 专属独立托盘图标 (Pet Tray)       │
│ • Agent 运行内核与模型通信        │       │ • 状态机、交互引擎、程序化动画     │
└────────────────┬────────────────┘       └────────────────▲────────────────┘
                 │                                         │
                 │ 命名管道 IPC (Local\Fufucode.Pet.IPC)   │
                 └─────────────────────────────────────────┘
                   广播: TaskStarted, Thinking, ToolRun,
                         WaitingApproval, Succeeded, Failed
```

1. **完全解耦**：
   - 宠物进程独立运行（内存开销仅 ~25-35 MB）；
   - 主窗口打开、隐藏至托盘、重启或退出，都不影响宠物的存活；
   - 宠物崩溃或被用户单独退出，绝对不影响 Fufucode 正在跑的编码任务。
2. **专属系统托盘菜单（Pet Tray）**：
   - `唤醒 Fufucode 主窗口`
   - `--------------------`
   - `宠物状态：[✓] 打工模式  [ ] 摸鱼陪伴  [ ] 安静睡眠`
   - `切换形象 / 皮肤 ▸`（快速换装）
   - `置顶显示`（单选切换）
   - `鼠标穿透`（防误触锁定）
   - `--------------------`
   - `隐藏宠物`
   - `退出 FUFU`

## 三、 美术管线：AI 生成图 + 程序化形变引擎

针对 AI 绘图在生成逐帧序列时“每一帧画风、线条会微漂移、无法像传统手绘般直接播放连续帧”的行业痛点，FUFU 采用 **“三层合成渲染引擎”**：

```text
┌────────────────────────────────────────────────────────┐
│  图层 3: 矢量/贴花叠加层 (Overlays & VFX)                │
│  (对话气泡、汗滴、愤怒小十字、心心、灵感灯泡、Zzz睡眠气泡) │
├────────────────────────────────────────────────────────┤
│  图层 2: 程序化形变层 (Avalonia Procedural Transform)   │
│  (果冻弹性微缩放、上下浮动呼吸、左右微倾斜、抓取下垂拉长) │
├────────────────────────────────────────────────────────┤
│  图层 1: AI 生成关键态单图 (Base State Art)              │
│  (Idle, Thinking, Coding, Success, Error, Tired, Sleep)│
└────────────────────────────────────────────────────────┘
```

### 3.1 AI 角色关键态资产规范

创作者只需为每个形象（Skin）提供 6~8 张高质量 AI 静态单图（透明背景 PNG）：

| 状态 ID | 形象描述 | 触发时机 | 叠加程序化动效 |
|---|---|---|---|
| `idle` | 萌宠常态发呆、眨眼 | 桌面日常空闲 | 慢速呼吸微浮动（周期 3s，Y 轴位移 ±3px） |
| `thinking` | 咬指头、托腮或头顶问号 | Agent 正在调用 LLM 深度思考 | 身体微左右倾斜，头顶浮现灵感齿轮/旋转小光圈 |
| `coding` | 狂敲微型小键盘、戴小眼镜 | Agent 正在写入代码或执行 Bash 命令 | 双手快速微振动，伴随敲击小火花/代码粒子 |
| `approval` | 探头举牌、招手示意 | 触发权限审批、需要用户确认 | 上下小跳跃（Bounce），弹出提示标牌 |
| `success` | 欢呼撒花、举杯、比心 | 本轮任务完成、测试全部通过 | 欢快弹性缩放（Scale 1.05x），周围飘撒花瓣 |
| `error` | 抱头委屈、抓狂或拿小锤砸地 | 任务失败、编译抛错、连接断开 | 身体轻微颤抖，头顶冒出汗珠或乌云贴图 |
| `sleep` | 趴着闭眼打瞌睡 | 深夜、或系统长期无操作 | 极慢微呼吸，头顶缓慢升起飘动的 `Zzz` 气泡 |

### 3.2 动作平滑过渡机制（Cross-fade + Spring Pop）

当 Agent 状态由 `idle` 切换为 `coding` 时：
1. 底图使用 180ms 的交叉溶解淡入淡出（Cross-fade），消除图片切换的生硬突兀感；
2. 配合 120ms 的微弹跳缩放（`ScaleX/Y: 0.95 -> 1.05 -> 1.0`），赋予 AI 静态图有机的生命感。

## 四、 丰富桌面交互体系（对标 GitHub 优秀实践）

### 4.1 鼠标手感与趣味互动 (Poke & Touch)

- **单击 (Click)**：轻微受击缩放反应，角色做出眨眼或偏头动作，播放轻微拟音（可静音）。
- **连戳抗议 (Rapid Clicks)**：连续快速点击 5 次以上，FUFU 触发委屈/抗议动画（如“不要戳啦！在努力写代码呢！”）。
- **拖拽体验 (Drag & Pick up)**：
  - 鼠标按下并移动超过 5px 时，进入“被揪起来”悬空状态（角色身体拉长、小脚悬空乱蹬）；
  - 松开鼠标时，在桌面位置就地弹性恢复（Spring landing）。
- **抚摸悬停 (Hover)**：鼠标悬停在头部区域时，角色做出闭眼享受表情或身体微微上迎。

### 4.2 气泡通知与快速拖拽投喂 (Bubble & Drop Feeding)

- **智能气泡 (Speech Bubble)**：
  - 当 Agent 输出重要结论、或者遇到问题时，宠物头顶浮现半透明圆角文字气泡（显示最新摘要）；
  - 点击气泡一键展开 Fufucode 主窗口并滚动到该位置；
  - 气泡展示 5 秒后自动向内收缩淡出。
- **桌面拖拽投喂 (Drop Action)**：
  - 允许用户从 Windows 桌面或文件资源管理器将文件（如代码文件、图片、日志文件）直接拖放到 FUFU 身上；
  - 触发喂食动画，同时唤起 Fufucode CLI 对该文件执行快速分析。

### 4.3 时间感知与环境作息 (Circadian Awareness)

- **晨间问候 (07:00 - 09:00)**：第一次鼠标掠过时，冒出气泡“早上好！今天也要写出优雅的代码~”；
- **久坐提醒 (连续工作 > 90 分钟)**：FUFU 做伸懒腰动作，提示“站起来喝杯水吧”；
- **深夜守护 (23:00 之后)**：FUFU 换成打哈欠/戴睡帽状态，提示“很晚了，注意休息哦”。

## 五、 分阶段落地路线图

```text
┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐
│     Phase 0     │ ───▶ │     Phase 1     │ ───▶ │     Phase 2     │
│   独立微进程跑通  │      │  状态机与程序化动效 │      │  丰富互动与投喂   │
└─────────────────┘      └─────────────────┘      └─────────────────┘
 • Fufucode.Pet 进程      • 基础 6 态 AI 图加载     • 戳戳乐与快速连点抗议
 • 透明无边框窗口           • 程序化呼吸/形变引擎     • 拖拽揪起悬空挣扎
 • 专属托盘图标与菜单       • 状态间平滑切换淡入淡出   • 头顶智能气泡与拖拽投喂
 • 自由拖拽与位置持久化     • IPC 接入 Agent 状态     • 外部换装 (Skin) 目录
```

- **P0 验收门**：双击启动 `Fufucode.Pet` 呈现透明悬浮窗口，可任意拖动位置并记忆，托盘区展示独立图标，右键菜单可唤出主窗口或退出，不抢代码编辑器焦点。
- **P1 验收门**：接入 IPC 广播，随着 Fufucode 运行任务，宠物实时从 `idle` 切换到 `thinking`、`coding`、`success`，过渡平滑无闪烁，呼吸弹动自然。
- **P2 验收门**：完成戳戳抚摸、连击抗议、拖拽悬空、气泡展示与文件拖拽投放。
