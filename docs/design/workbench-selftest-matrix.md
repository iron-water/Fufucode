# 工作台详细自测表

日期：2026-10-05。适用：桌面 Demo 重写。先定义验收，再实施与填结果；未执行不得写通过。HTML 只作历史功能参考，不作视觉基准。

## 统一风格与验收规则

- 工作台采用同一套 Fluent 字体、灰阶、蓝色强调、边框、图标与间距；不混用网页式胶囊按钮、自绘文字符号和不同选中规则。
- 每个停靠区只有一条页签栏，不另设重复的页面标题/位置工具栏。页面位置和关闭动作集中在页签菜单；常用开关使用带 tooltip 的图标。
- 中央对话为主，默认左右收敛、底部终端收起；用户打开后可以调整。宽度不足时侧栏采用互斥抽屉，始终保留标题、输入区与关闭入口。
- 验证尺寸：1440×900、1200×800、900×700、800×640；明暗主题；长名称/路径/文本；空、加载、正常、错误、不可用状态。
- 每项记录：`待测`、`通过`、`失败`、`未实现`、`受限未测`；证据区分源代码审查、无头控件行为、产品截图、Windows 实机操作与真实 Pi。源代码不能代替运行证明。

### 本轮发现与修正

1. 页签下方重复位置/标题栏、终端冗余标题：移除，位置与排序集中到页签菜单。
2. 搜索图标缺失、字符图标混用、输入焦点不一致：补齐既有 Fluent 图标资源，统一输入模板和蓝色强调。
3. 800×640 展开终端后空态越界：缩小插画，校验输入和中央区域可用尺寸。
4. 窄窗口仍同时挤入左右栏：自动收起、显式打开互斥抽屉，不覆盖保存宽度。
5. 页面关闭/移区重建浏览器：关闭后停放实例，同帧移区保留 WebView2；主窗口关闭显式释放。
6. WebView2 盖住全局浮层：浮层期间隐藏 Native controller，关闭后恢复。
7. 活动页签移入拥挤区域后不可见：选中项滚入可见范围；区内排序可保存。
8. 关闭运行终端没有确认：增加确认、重复点击保护，并验证取消和接受两个分支。
9. 引用草稿名称冒充独立问答、跨会话归属不清：改名、空态禁用、按会话保存草稿。
10. RPC 关闭竞态：观察独立 waiter 错误；并发回归发现关闭流异常外泄，统一为保留原因的 PiRpcException，不放宽测试断言。
