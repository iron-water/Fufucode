# Fufucode 前端交互草案

直接打开 `index.html`。无需安装、开发服务器或联网；保持此目录与仓库 `assets/` 的相对位置。

配套功能规划：`../design/frontend-functional-plan.md`。方案尚待用户确认，示意页不代表 Avalonia 已交付。

2026-10-06：默认样式同步已交付工作台的蓝色强调、中性表面、页签、输入区及 232/320/240 默认区域尺寸，样式集中在 `workbench.css`。已有浏览器布局不强制重置，可使用恢复默认。1440×900、390×844 与窄屏深色设置页已截图检查；示例功能和风格探索仍不代表应用完整实现。

## 可以试的交互

- 标签切换、增加、关闭；通过位置菜单或跨区拖动将页面移到左、右、底。
- 拖动区域分隔条调整尺寸；布局保存在当前浏览器本地；状态栏可恢复默认布局。
- 文件预览切换 Markdown、代码、图片、PDF、Office 降级示例。
- 浏览器地址、终端输入、侧栏提问与回答引用、主会话草稿和示例消息。
- 消息操作条、分支/重试/分享示意弹窗、会话刻度、摘要卡、设置与主题。
- 窄屏使用顶部“对话 / 左区 / 右区 / 底区”切换，避免多栏挤压。

## 限制

示例数据不会读取真实项目文件、调用模型、运行命令、访问网站、生成公开分享或播放声音。公式、流程图和 PDF 是固定排版示意，不是完整解析器。会话切换只切换示例标题，不是持久化的实际会话。

正式版规划的区内拖动排序、多实例页面、滚动与草稿状态跨区保留、图片缩放、搜索完整匹配等尚未在此简易原型实现。

图标来自本地打包的 Lucide，许可证见 `LUCIDE-LICENSE.txt`；应用图标引用已有 `assets/icon/`，未另行设计品牌资产。
