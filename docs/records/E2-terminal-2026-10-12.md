## 实施规则与假设（最保守可用选择）

1. **选择绑定快照，不借旧索引**：选择记录所选时刻的 `TerminalSnapshot` 实例（tab 缓存到缓冲变化为止），复制始终从该冻结快照解析文本。输出重写、新输出、回滚截断后，旧选择的文本不变、不会被新文本顶替；同一快照被替换后拒绝继续扩展，高亮隐藏（不把旧索引画到新文本上），复制仍返回当时所选内容。
2. **窄字符/宽字符/组合/emoji**：`TerminalCell` 文本按整码点存储，续格文本为空。提取时跳过续格贡献；起选落在续格时回退到 owner 格，避免拆字。每行去尾部填充空格，整段去尾部空行，中间空行保留；快照已解释 ANSI，不夹带转义序列。
3. **零长度手势 = 无选择**：单击（起止同格）视为清除选择，复制入口随之禁用；单格选择需拖到相邻格。
4. **复制/中断分流**：`Ctrl+Shift+C` 恒为复制；`Ctrl+C` 有选择时复制、无选择时仍发 `\u0003` 中断；shell 退出后复制/查找/返回底部仍可用，不因进程结束禁用输出操作。
5. **粘贴只入草稿**：终端表面的 `Ctrl+V` / `Shift+Insert` 读取剪贴板，`\r\n`/`\r` 归一化为 `\n`、去除 NUL，追加合并（两侧非空且边界无换行时补一个 `\n`），不覆盖、不截断、不写入 shell。命令框内的系统粘贴仍是 TextBox 原位插入（同样不覆盖整条草稿、不自动运行）。运行只能由「运行」按钮或命令框 Enter（原发送入口）触发。
6. **查找只查有界缓冲**：查询针对当前 `TerminalSnapshot`（≤1500 行回滚 + 屏幕）按需扫描，只保留命中列表，不缓存完整输出副本，渲染期只读 `Current`。输出变化后导航前先按新快照重跑并就近定位，绝不把旧命中索引用于新文本。大小写开关为 Option；无命中显式显示「无匹配」；查找不向 shell 发送按键。
7. **方向键边界**：终端表面仍把方向键转义序列发送给 shell；只有命令框在「光标在首行按 ↑ / 末行按 ↓」且自身非浏览态时浏览本地历史，多行草稿保留光标移动。
8. **历史界限**：每 tab 内存历史上限 100 条，仅记录用户显式提交的非空命令（`.Trim()`），与最新一条相同则折叠；不落盘、不上载、不跨 tab/项目共享。`↑` 记下未发送草稿，`↓` 到底恢复原草稿。
9. **返回底部**：显式按钮恢复 `FollowOutput = true` 并滚到底；查找定位与手动滚动会把跟随置为 false（阈值沿用既有 36px 规则），新输出不抢滚动。
10. **每 tab 隔离**：选择、查找查询/命中/开关/开关状态、命令历史、滚动偏移与草稿都在 `TerminalTabViewModel` 上，切 tab / 隐藏 / 重挂 / 关闭互不影响；关闭 tab 才 Dispose，隐藏与重挂不重启也不重复订阅。
11. **320 宽与明暗**：工具按钮沿用 `iconButton toolButton` 28px 命中区与既有图标资源；查找条用 `AppInnerWell`/`AppBorderBrush`。终端表面按既有约定保持固定深色（ANSI 默认色对齐），选择/命中高亮取与之协调的固定半透明色。

## 缺陷 1：E2-PASTE-TARGET-1（异步粘贴改投）

**根因**：`TerminalScreenControl.PasteToDraftAsync()` 在 `await ReadClipboardAsync()` **之后**才读取 `Session`，因此剪贴板读取期间切换 tab，会把 A 发起的粘贴写进 B 的草稿。

**修复与明确行为**（`TerminalScreenControl.cs` + `TerminalDockViewModel.cs`）：

1. 在 `await` **之前**绑定发起时的 tab；读取完成后只写该 tab 的草稿，永不改投当前选中 tab。
2. 发起 tab 已关闭（新增 `TerminalTabViewModel.IsDisposed` 只读属性）→ 直接丢弃，不写入已 Dispose 对象、不回落其它 tab、不抛异常。
3. 草稿焦点交接（`PasteCompleted`，页面据此聚焦命令框）仅在**发起 tab 仍是当前选中 tab**时触发；切到/隐藏到其它 tab 后完成粘贴不抢焦点。
4. 隐藏/重挂不影响目标绑定：目标只由发起时的 tab 决定。

## 缺陷 2：E2-SELECTION-GRAPHEME-1（选择拆字素）

**根因**：`TerminalSelectionText.Extract` 只按固定格逐格取文本，`TerminalBuffer(20,3).Append("Ae\u0301X")` 下 `Extract(snapshot,(0,0),(0,1))` 得到 `Ae`，丢掉组合附加符 U+0301。

**修复与规则**（`TerminalOutputSelection.cs`，未改 `TerminalBuffer`/ConPTY）：

1. 新增 `Resolve(snapshot, first, second)`：归一化 → 夹取 → **字素簇扩展** → 宽字符续格回退 owner；`Extract` 与页面高亮共用同一 `ResolvedRange`，所见即所复制。
2. 字素扩展判定：Unicode Mn/Mc/Me（组合/包围符）+ ZWJ(200D)/ZWNJ(200C) + 变体选择符 FE00–FE0F、E0100–E01EF + emoji 肤色修饰符 1F3FB–1F3FF + keycap 20E3。
3. 尾部扩展：下一个格是扩展码点，或当前格是 ZWJ（其后基字符属于同一簇）时并入。
4. 起选扩展：起选格本身是扩展码点，或其前一格是 ZWJ 时向前并入基字符；随后沿用既有续格回退规则，中文宽字符不被拆开。
5. **行边界仍是硬边界**：字素扩展不跨行（组合符换行到下一行时不并入上一行、不丢换行）；零长度手势仍视为无选择。
6. 原有快照冻结/回滚截断保护不变。

## 缺陷（真实 TerminalBuffer 复现）

M 忠实反例 `tmp/m-e2-grapheme-width-red.log`：`TerminalBuffer(30,3)` 下选 `(0,0)..(0,1)`：

| 输入 | 实际 | 期望 |

| `A👨\u200D👩X` | `A👨` | `A👨\u200D👩` |
| `A🇨🇳X` | `A🇨` | `A🇨🇳` |

同一 ZWJ 例选 `0..4` 完整，定位为**边界缺口**而非整体失败。

根因 1：字素扩展在**宽字符续格**（`TerminalCell.Text == ""`）处提前终止——续格既不是扩展码点也不是 ZWJ，于是 owner 之后的组合符 / ZWJ / 后半表情都取不到。
根因 2：先前手写的扩展类别没有 UAX#29 GB12/GB13 的**区域指示符配对**，旗帜被拆成两个单字符。

## 修复（整行字素边界 + 真实 cell 映射，等价准确方案）

`TerminalOutputSelection.cs`（未改 `TerminalBuffer`/ConPTY/MainWindow/共享入口）：

1. `Resolve` 改为：取整行文本（跳过续格）→ `StringInfo.ParseCombiningCharacters` 求文本元素边界（.NET 10/ICU 完整 UAX#29：组合符、变体选择符、ZWJ 表情序列、区域指示符配对）→ 把边界映射回 cell。
2. cell 映射：`RowCells` 记录每个有文本 cell 的 (列, 文本起点, 文本长度)；续格用「不大于该列的最大 cell 列」解析回 owner，因此宽字符 owner 与续格始终成对。
3. 起点取簇首 cell；终点取簇末 cell，且当终点是宽字符 owner 时并入其续格——**高亮与复制共用同一 `ResolvedRange`**（页面每帧只解析一次）。
4. **行内边界**：解析只在单行内进行，真实换行仍是硬边界（组合符换行到下一行时不并入上一行、不丢换行）。零长度手势仍视为无选择；快照冻结与回滚截断保护不变。
5. 删除先前手写类别判定，避免再次漏 UAX#29 规则。
