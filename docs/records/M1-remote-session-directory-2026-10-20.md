# M1 手机端与桌面端会话联动

## 本轮目标

桌面端已升级为多项目/多会话工作台。此前手机远控只绑定一个会话，桌面切换会重建监听并令手机令牌失效；本轮补齐会话目录、会话切换和切换后的稳定快照。

## 实现

- 新增认证端点 `GET /api/sessions`：返回当前桌面会话、项目名、后端、置顶/未读状态和 `canSwitch`。不返回文件路径、令牌或正文。
- 新增认证端点 `POST /api/sessions/switch`：把会话 ID 交给桌面组合根，由 Avalonia UI 线程执行真实切换；忙碌、回合进行中、设置页或跨项目未信任时明确拒绝。
- 远控会话桥改为稳定对象：切换只重绑 `IChatSession`，不重启监听、不轮换 PIN、不让已配对手机失效；旧会话迟到事件按发送者身份丢弃。
- 手机抽屉读取真实目录，显示项目/后端/置顶/未读，并在桌面受理后刷新快照与当前会话。
- 手机端新增 Wire 解析、目录刷新、切换在途去重、拒绝不伪装成功及 401 失效处理。

- Android JVM：`:app:testDebugUnitTest`，**46 项全部通过**；`:app:assembleDebug` 成功。
- App 隔离输出构建：`dotnet build src/Fufucode.App/Fufucode.App.csproj`，0 errors；4 条既有警告来自 `WorkspacePanelView`/`ToolOutputView`，本轮未修改。
- 当前工作区有一个既有设置页 WIP 的 `SettingsLayout` 静态类型编译错误；为完成本轮验证，临时把该类改为可注册 Avalonia 附加属性所需的非静态类（未纳入本轮提交）。

## 未验证

- 未在当前运行中的桌面窗口上做手机真实切换；桌面进程锁定了默认输出目录，本轮使用隔离输出构建，不终止用户进程。
- 未进行真机/模拟器的会话目录点击截图验证；Android 测试使用状态机夹具，不等于原生交互验收。
- 跨项目切换要求目标项目已在桌面端信任且文件夹存在；未自动代替用户在电脑端完成信任决定。
- UU 远程仅作为独立桌面远控入口，不承载 Fufucode 会话协议。
