# FUMO 长程能力实测与可靠性修复（2026-10-22）

## 目标与口径

用 `devin/swe-2` 在真实 Flutter 项目上跑“同一任务、多次重复”的长程开发，按用户给定权重评价：

| 维度 | 权重 | 口径 |
|---|---:|---|
| 完成度 | 70% | 隐藏验收 50% + 既有测试 25% + `dart analyze` 无 error 15% + 种子校验 10% |
| 用时 | 20% | 墙钟时间；任务 A ≤20 分钟满分、≥60 分钟 0 分；任务 B ≤35 分钟满分、≥90 分钟 0 分 |
| 用量 | 10% | billable tokens =（输入 − 缓存命中）+ 输出；≤300k 满分、≥2M 0 分；同时记录总 tokens 与缓存命中 |

不把“看起来完成”当完成：隐藏验收测试由评测方持有，运行前才复制进工作区，模型不可见。未运行的项不记为通过。

## 失败分类与根因

1. **网关以 SSE `error` 帧报告上游断流**（`the reply broke off: ECONNRESET`）。它不是 HTTP 错误，也不是 Socket 异常；原实现把它归为 `StreamError` 后直接判死。
2. **流式已输出部分内容后断流**。原实现只在“尚未输出任何增量”时重试，长回合已经跑了几十次工具调用也会整轮丢失。
3. **`HttpClient` 内置 100 秒超时**。长推理请求被一个没人配置过的默认值终止，且错误信息与用户取消混在一起。
4. **恢复历史可能缺 `tool_result`**。进程在工具执行途中被强杀时，持久化的 `assistant(tool_calls)` 后面没有配对结果，下一次请求会被 API 拒绝。
5. **回合结束才落盘**。长回合中途崩溃会丢掉整轮已完成的工具结果。
6. **用量不可见**。流式请求没有 `include_usage`；`MessageFinished.CumulativeUsage` 恒为 null；CLI 只取最后一次 usage。导致“用量”无法测量，也无法据此判断压缩时机。
7. **终态被洗白**。`PromptHandled` 每个回合都触发，CLI 可能把截断/失败显示成 `handled`。

## 修复

- **回合内压缩**：每轮模型请求前检查；窗口来自 `/v1/models` 的 `context_length`，阈值 85%；窗口未知时只保留 2M 字符物理内存保护，不再使用 400k 字符固定阈值；上下文超限错误触发一次强制压缩并重试同一轮。
- **流式重试与降级**：429/5xx/传输层最多 3 次；已输出增量时先 `OnRestart` 关闭半成品再重放；SSE `error` 帧中的 ECONNRESET/upstream/connection 等按瞬时故障处理；连续失败后改用一次性请求完成本轮。工具在响应完成后才执行，重放无副作用。
- **移除隐藏超时**：内部 `HttpClient.Timeout = InfiniteTimeSpan`；只有调用方显式 `RequestTimeout` 才限制。注入的 HttpClient 超时归类为可重试传输失败。
- **恢复配对修复**：补齐缺失 `tool_result`，丢弃孤立结果；压缩后同样校验配对。
- **长回合节流落盘**：工具轮后每 5 秒最多写一次，终态仍完整落盘。
- **用量可信**：流式 `include_usage`（网关不支持时自动降级）、`MessageFinished` 携带 usage、CLI 汇总 `totalUsage`。
- **终态不被覆盖**：`PromptHandled` 仅在真实没有产生回合时生效。
- **命令超时**：默认 120s → 300s（构建/测试常态），上限仍 600s。
- **Win32 截图**：只读截图不再要求前台；输入动作仍要求显式 foreground。

## 向五个核心学到的、真正落地的部分

- **Claude Code**：按模型上下文窗口自动压缩、计划/待办跨压缩保留、权限模式分层。FUMO 已对齐“真实窗口 + 85% 阈值 + 计划快照”。
- **Codex**：以模型终态结束循环、持久化 rollout、失败可恢复。FUMO 已对齐“无默认轮次上限 + 增量落盘 + 配对修复”。
- **Pi**：`agent_settled` 才是可靠终态、steer/follow-up 分层。FUMO 已对齐 `TurnSettled` 与 steer 队列。
- **OMP / DSH**：超时、看门狗、任务预算属于无人值守/任务级策略，不应下沉为交互主会话的默认硬限制。FUMO 只在调用方显式传预算时启用。
- 没有照搬的：多 Agent 编排、模型自动降级、固定任务看门狗。这些要么与当前单模型定位无关，要么缺少本机证据。
