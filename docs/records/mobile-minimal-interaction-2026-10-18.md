# 安卓前端：简洁与按需展开

## 用户决定与范围

用户要求简洁清新，减少繁冗说明，优先通过图标、视图、动效和交互解释功能。
本轮只改安卓配对页和聊天页，不改远控协议、桌面端或其他在途任务。

## 已实现

- 配对页移除宣传副标题、初始“未连接”标记和发现区域重复说明。
- 连接帮助保留按需展开，压缩为三个操作步骤。扫描范围仅在帮助展开时显示，扫描进度仍可见。
- 已完成工具卡保留成功图标和工具名，详细状态文字移入展开区；失败、执行中和待审批状态仍直接展示。
- 工具详情箭头在展开与收起时旋转，过渡160ms；保留最小触摸高度及无障碍状态描述。
- 输入提示缩短；多个附件可横向滚动，避免挤出屏幕。
- 审批按钮改为“允许一次”，移除重复授权范围说明；实际参数、拒绝入口和失败原因保留。
- 修复选中自动发现电脑后的焦点：将父级 FocusRequester 传入真正的配对码输入框。
- 用户重新编辑地址或配对码时清除旧的表单校验错误。
