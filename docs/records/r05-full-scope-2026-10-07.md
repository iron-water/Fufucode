## 最新三项修正

- 色调：同步完整 Fluent 派生色和原生控件画刷，深色使用 UniGetUI 相同的 Light2/Light3 层级；默认跟随系统，Fluent 恢复 Mica 请求；隐藏重复的旧主题编辑入口，避免两个配置源冲突。
- 返回：扩展页独立返回按钮、Esc 返回、Alt+左导航；保留设置 dirty/busy 门禁。分叉弹窗 X 关闭不再把整数默认值 0 当作确认。恢复归档后关闭选择窗口。顶栏溢出进入菜单，800 像素窗口保留设置入口；搜索提示不扩大按钮并挤掉后续入口。
- 图标：补齐置顶、归档、分叉、通知、附件、导入导出、撤销重做、剪切粘贴、缩放及全屏等真实资源，给动作菜单加图标。这些动作不再退回通用列表图标。Microsoft Fluent System Icons，MIT，来源提交 `08130c218d6bb87767d6d5616d9afcea651146c7`；许可证随输出保存在 `Licenses/`。

同时修正时间线丢失运行时消息 ID、追加意见菜单后固定页签禁用错项、项目布局误引用前一项目 UI 覆盖的问题。关闭项按明确标识定位。
