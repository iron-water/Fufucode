## 实现对照

| 意见 / 功能 | 正式应用行为 |
|---|---|
| 状态栏项目、分支、恢复默认布局、保存提示 | 状态栏可整体隐藏；每个功能可迁移到顶栏、更多菜单、会话菜单或左右状态栏，并排序/隐藏；配置保存提示留在设置页 |
| 顶栏品牌、交互草案、工作台标题 | 顶栏改为功能入口和真实会话名；无原型说明文字；会话头默认隐藏，可在设置显示 |
| 核心/辅助功能位置 | 使用统一动作目录，默认核心在左、辅助在右；外观设置可逐项更改位置与顺序 |
| 搜索会话与功能 | 共用命令目录和会话检索；搜索入口随鼠标靠近展开、离开收起 |
| 左/右/底区开关 | 保留独立开关；右栏存储宽度取消旧 700px 上限，实际尺寸受窗口剩余空间约束 |
| 页签固定与原位置小设置 | 页签菜单固定/取消固定、移动、排序、关闭；固定时关闭按钮和菜单禁用，布局保存保留固定状态 |
| 状态左右顺序 | 默认左侧 Pi/Shell 等会话外连接，右侧活动等会话内状态；可配置；未取得 Token 显示未知 |
| 自定义用户/助手名 | 展示名可配置，用户信息靠右；可选择将名称偏好加入模型请求 |
| 输入模型与思考等级 | 模型/强度位于输入区右侧；查询当前 Pi 支持列表；default 清除覆盖，max/ultra/auto 等无运行时支持的档位显示不可用原因 |
| 输入区宽/窄/隐藏 | 宽、与阅读列同宽、隐藏三个模式；统一命令可恢复输入区 |
| 每轮摘要与生成产物 | 每轮最后一条回复承载变更和产物卡；只纳入已成功的直接 write/edit；产物链接进入现有文件预览 |
| 权限模式与图标 | plan、manual、auto、full 通过桥接命令执行；plan 允许 read、拒绝写入和 Shell；auto 自动批准文件写入，Shell 仍确认；full 放行；manual 确认 |
| 设置再次点击返回 | 同一设置动作再次执行返回主工作台，导航历史支持前进/后退 |
| 拖入文件与图片/PDF | 文件选择器和拖放共用加载路径；图片以 Pi images 字段发送；文本附上下文；PDF/其他二进制保留明确文件引用，不冒充已解析内容 |
| Markdown 草稿 | 加号菜单切换渲染预览，保留原文编辑；回形针专门添加文件，加号承载附加功能 |
| 新聊天、临时聊天、新窗口、打开文件夹、关闭/退出 | 连接实际会话/窗口操作；临时聊天使用隔离数据目录并继承模型和认证配置；认证入口映射模型认证管理 |
| 会话置顶、未读、重命名、归档 | 本地持久化展示状态；归档可从已归档列表恢复；复制项目/会话/日志路径及会话 ID |
| 会话/消息分叉、重试 | 选择真实 Pi user entry；保留父历史；重试明确提示工具可能再次执行；修正子会话 ID 使其与 Pi 实际 ID 一致 |
| 侧边聊天 | 独立 Pi 会话/进程和审批宿主；主会话不接收旁路消息；关闭和换项目时释放 |
| 计划任务 | 按会话持久化到期时间；运行中空闲会话可自动提交或到期提醒；提交前持久化领取，避免多窗口或崩溃后盲目重复 |
| 分享、复制、导出、在新窗口打开、打开方式 | 本地 Markdown 导出与复制；新窗口前转交独占会话；系统默认程序及已安装编辑器打开项目 |
| 编辑动作 | 原生输入控件撤销/重做、剪切/复制/粘贴、删除、全选 |
| 视图动作 | 侧区、终端、浏览器、导航面板、摘要、对话/功能页焦点切换、查找、相邻聊天、返回/前进、缩放与全屏 |
| 帮助与诊断动作 | 本地文档、快捷键、新功能记录、故障排除、系统状态、进程概览、性能采样、导出问题报告、发布查询、关于 |
| 消息操作与播报 | 保留复制、引用、选区辅助和本地评价；接入真实分叉与 Windows SAPI 朗读/停止，可自动朗读完成回复 |
| R05 自定义参数 | 系统/浅/深主题、强调色、字号、圆角、密度、阅读宽度、消息操作条、头像/名称/时间、会话刻度和两类摘要显隐；标准/紧凑/阅读预设 |
| 配置管理 | 全局 ui.json 与项目 .fufucode/ui.json 稀疏覆盖；撤销/重做、范围重置、清除项目覆盖、JSON 编辑与文件导入/导出；保留未知键及不支持版本原件 |

## 能力边界

- 本轮真实模型协议验证使用本地脚本模型，不代表新的外部供应商质量验收。
- PDF 附件是文件引用；未增加 PDF OCR 或抽取器。图片是否被模型理解取决于所选模型能力。
- 分享为本地导出，无公开分享服务。账号退出映射产品退出与模型认证管理；未建立新账号体系。
- 无配置发布仓库时更新查询报告明确错误；本仓库当前没有 origin，在线 release 检查未验证。不会自动安装更新。
- 计划任务要求应用运行且对应会话处于活动/空闲状态；不提供关闭应用后的后台唤醒。
- 产物卡来自已成功的直接文件工具；不会把任意 Shell 输出推断为完整 Git 变更或生成产物。
- 文件选择器系统对话框、物理拖放、声音实际播放及外部编辑器启动未逐项进行人工验收；共享加载/状态链路和代码接线已验证。R04 三种视觉风格未被 R05 原型采纳，本轮未额外扩展。

入口：`tmp/r05-build/Fufucode.App.exe --mock`；真实模式使用相同程序的现有项目/模型配置路径。第三方 reference 保持只读；不推送。
