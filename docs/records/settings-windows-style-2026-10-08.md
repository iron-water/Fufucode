# 设置页改版：对齐 Windows 设置（2026-10-08）

用户反馈：设置页"太丑，且没有二级菜单跳转，全堆在一块"。本轮按 Windows 内置设置的设计语言重做。

## 参照的 Windows 设置特征

对照用户提供的「系统 > 屏幕」截图，提取到五条可复用的语言：

1. **左栏导航**：图标 + 文字，选中态为浅色圆角底 + 左侧 3px 强调竖条。
2. **面包屑**：内容区左上显示「系统 > 屏幕」，二级页时旁边有返回箭头。
3. **分组标题**：卡片之外的独立小标题（如「亮度和颜色」「缩放和布局」）。
4. **分组卡片**：一个分组一张圆角卡，卡内多行用细分隔线分隔；而不是"每项一张卡"。
5. **行式条目**：左标题 + 说明，右侧放控件；需要下钻的行右侧是进入箭头。

## 本轮改动

### 左栏导航
- 八个分类各配图标（外观=调色板、功能=列表、配置文件=代码、模型与思考=脑、网络与端点=地球、通知=铃铛、工作台模块=拼图、关于=信息）。
- 新增 `SettingsIconConverter` 把图标键名解析成几何资源，取不到时回落到设置图标。
- 选中态：浅底 + 左侧强调竖条（`Border.navAccent`），未选中项图标用次级文字色。

### 二级页导航
- `SettingsPageViewModel` 增加 `CurrentPageId` / `Breadcrumb` / `IsSubPage` / `ActivePageId` / `OpenPage` / `GoBack`。
- 外观分类拆为两级：「外观」首页放主题、颜色、字体与密度，另有入口行「前端功能排布」下钻到子页。
- 功能分类拆为三级页面：「会话与消息」「名称」「浮窗」。
- 切换左栏分类时回到该分类首页，不会停留在上一分类的子页。
- 面包屑形如「外观 › 前端功能排布」，返回箭头回到分类首页。

### 分组卡与行式条目
- 新增共享样式与构件 `SettingsLayout`：`Group`（分组卡）、`Row`（普通行）、`ChevronRow`（下钻行）、`GroupHeader`、`Note`。
- 全部设置项改为「分组标题 + 一张卡 + 多行」，行内用分隔线，最后一行去线。
- 行内点击只在整行（非控件区域）触发下钻；下拉、开关、按钮自行处理点击。

### 覆盖的页面
- 外观、前端功能排布、会话与消息、名称、浮窗、配置文件：由 `WorkbenchSectionsView` 重建。
- 模型与思考、网络与端点、通知、工作台模块、关于：改为同样卡行结构，保留原有全部绑定与表单。

## 期间修掉的问题

- 响应式代码仍按旧结构移动滚动区，改结构后抛 `ArgumentOutOfRangeException`；改为移动新的内容容器。
- 选中竖条被模板里的 `IsVisible="False"` 压过，样式不生效；改为只由样式控制。
- 分组行的重载把 `Border` 误绑到 `title` 形参；补显式重载并让无标题调用传空串。

## 未做与边界

- 未做 Windows 设置那套「相关支持」底部链接区。
- 搜索仍按分类过滤；二级页内的行过滤尚未细化到行级。
- 未逐像素对照 Windows 设置的实际字号与间距，只对齐了结构语言。
