# 功能页两栏、顶栏对齐、图标统一与 mock 演示会话（2026-10-07）

承接 `docs/records/visual-unification-2026-10-07-c.md`。

## 一、功能页分为两栏

功能页改为并排两栏：

- **左栏：侧边栏功能**。列出当前落在「核心功能（侧边栏）」位置的动作，每个可改位置与顺序；下面是会话与消息相关设置（消息操作、输入区、会话头、会话刻度、逐轮变更/产物摘要）。
- **右栏：辅助功能**。列出当前落在「辅助功能（顶栏菜单）」位置的动作；下面是显示类设置（状态栏、头像、用户名/助手名、消息时间）与名称设置。

分栏依据的是动作自身的 `UiActionPosition`（`MenuLeft` = 侧边栏功能，`MenuRight` = 辅助功能），不是另建一份分类表，因此两侧设置与顶栏实际出现的位置始终一致。某个位置暂无动作时，该栏显示说明而不是空白。

## 二、顶栏对齐与两个展开键

- 新增共享样式 `Button.captionSlot`：46×32 命中区、图标 16px、无圆角，与系统最小化/最大化/关闭按钮（`CaptionAssetButton` 同为 46×32）尺寸一致。顶栏动作按钮与代码构建的入口按钮都套用该样式。
- 顶栏溢出容量计算按 46px 步长更新（原按 33px 估算会溢出）。
- 两个展开键改名为**左辅助**与**右辅助**（用户暂定名，后续还会细化）：
  - 左辅助 = 原「核心功能」，图标改 `ChevronRight`；
  - 右辅助 = 原「辅助功能」，图标保持 `ChevronDown`。

## 三、底部面板默认关闭的原因与处理

`WorkbenchAppearance.ShowStatusBar` 与底停靠区可见性在代码里的默认值都是**开启**（`ShowStatusBar = true`、`Hidden` 全为 false）。

实际观察到关闭，是因为本机 `C:\Users\mio\AppData\Local\Fufucode\ui.json` 里保存的布局把三个停靠区都设为隐藏：

```json
"hidden": { "left": true, "right": true, "bottom": true }
```

该文件没有 `showStatusBar` 键，所以状态栏本身是开的。已做一次性重置（原文件另存 `.bak-<时间戳>`）：把三个 `hidden` 改回 `false`。颜色、名称、密度等设置未改动。

## 四、侧边栏图标形式统一

右侧边栏图标 `Icon.PanelRight` 是直角描边风格；`Icon.PanelLeft` 与 `Icon.PanelBottom` 原来是圆角路径，三者并排不统一。按用户偏好统一为直角风格：

- `PanelLeft` / `PanelBottom` 改为与 `PanelRight` 同构的直角几何（外框 + 强调侧条）。
- 顶栏左侧停靠开关原用 `PanelRight`（镜像），改用 `PanelLeft`；底部开关原用 `ChevronDown`，改用 `PanelBottom`。三个开关现在是同一套面板语义图标。
