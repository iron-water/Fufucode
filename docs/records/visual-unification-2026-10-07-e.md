# 摘要折叠、图标补全与窄窗适配（2026-10-07）

承接 `docs/records/visual-unification-2026-10-07-d.md`。本轮补齐交接说明里仍缺的项。

## 一、摘要可折叠（交接说明 §5）

交接说明要求"摘要折叠后成为简洁入口，并参与正常布局，不能悬浮遮挡正文或输入框"。此前摘要只能整体开关，不能逐条折叠。

- `TimelineEntryViewModel` 增加 `SummaryExpanded` / `SummaryToggleLabel` / `ToggleSummary()`。
- 摘要卡标题行改为可点按钮：展开时显示"本轮变更　折叠摘要 ⌃"，折叠后显示"本轮变更　摘要 ›"。
- 折叠只隐藏明细（变更清单文本），标题行仍在正常布局中占位，不产生悬浮遮挡。
- 修掉一处重复：摘要卡与"生成产物"卡同时渲染 `ArtifactLinksView`，同一产物列两遍。现在摘要卡只负责变更清单，产物卡独立。

## 二、专用图标（交接说明 §6）

- 新增 `Icon.More`（more_horizontal_20_regular）与 `Icon.ChevronRight`（chevron_right_20_regular），均取自 Fluent System Icons（MIT）。
- 原来用 `ChevronDown` 冒充"更多"的三处改用 `More`：消息操作"更多"、会话头"会话操作"、右辅助展开键。
- 这说明一个真实缺陷：上一轮「左辅助」用了 `ChevronRight`，但该资源**当时并不存在**，取不到几何会静默回退成通用图标。现已补齐。
- 全仓扫描确认：所有 `Icon.*` 与 `IconButton(...)` 引用的键都有对应资源，无静默回退。

## 三、未知时间不再显示占位值（交接说明 §6「不用假数据制造完整感」）

mock 与历史缺失的消息 `Timestamp` 为默认值，此前渲染成 `00:00:00`。

- `TimeText` 改为：未知时间返回空串，已知时间按 `HH:mm` 本地化显示；新增 `HasTime`。
- 消息时间仍受「消息时间」显示开关控制（用外层 `Panel` 绑 `UiShowMessageTimes`，内层绑 `HasTime`），两个条件都满足才显示，不因去占位值而丢掉用户设置。

## 四、设置页两栏窄窗自动堆叠

「外观」「功能」两页改成两栏后，设置窗口最小宽度约 420，两栏并排会把控件压到不可用。

- `WorkbenchSectionsView` 记录每对栏，`SizeChanged` 时按阈值 620 重排：够宽并排，不够则上下堆叠（各占 `Auto` 行）。
- 搜索过滤掉某一栏时，剩下的一栏占满整宽。

## 五、证据图反映默认观感

此前证据图是在用例中途拍的，继承了"隐藏状态栏、输入区隐藏"等测试状态，不能代表默认界面。

- 截图前先恢复默认：输入区全宽、状态栏开启、三区可见、密度舒适、阅读宽度标准。
- 文件名带上尺寸（`theme-light-1440x900.png`），避免宽高不符时误读。
