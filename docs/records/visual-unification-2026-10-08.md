# 底部状态栏默认关闭（2026-10-08）

用户澄清：他说的「状态栏」是窗口最底那条显示「已连接 / Shell 已连接 … 空闲 / Token」的细条，不是底停靠区。要求该细条**默认关闭**，需要时自己在「外观 → 前端功能排布」里开启。

## 改动

- `WorkbenchAppearance.ShowStatusBar` 默认值由 `true` 改为 `false`（仅默认值变化，不影响已保存的显式配置）。
- 设置里把该开关从「功能 → 显示」移到「外观 → 前端功能排布」，命名改为「底部状态栏」，紧邻三个停靠区显隐开关；补一句说明它显示连接、Shell、活动与 Token 等运行状态。
- 布局栏的搜索关键词加入「状态栏 / status」，保证搜索能命中。

## 验证

| 项 | 结果 |
|---|---|
| 构建 | 0 错误 0 警告 |
| `--selftest --r05-only` | 62 项通过 0 失败 |
| `--selftest --tabs-only` | 47 项通过 0 失败 |
| `--selftest --settings-destination-only` | 20 项通过 0 失败 |

新增两条断言：默认关闭时状态栏不可见；在布局栏开启后可见。证据图 `statusbar-on-1440x900.png` 为开启态，其余证据图为默认（关闭）态。

## 边界

- 状态栏关闭只影响这一条细条，底停靠区（终端）不受影响。
- 「阅读」预设原本就设 `ShowStatusBar = false`，与新的默认一致。
