# 工作台 Demo 交付记录

日期：2026-10-05。本次范围：HTML 原型落实为 Avalonia 工作台并连接已有能力，交付可试用增量；不宣称完整产品验收。

## 已落实

- 左、右、底部通用功能页宿主：打开、关闭、隐藏、跨区拖动和位置菜单、分隔条调整。页控件与位置分离，同一区切换不卸载其他页面。
- 概览/会话、文件、变更、文件预览、浏览器、引用草稿、会话目录、终端；中央对话和独立设置。窄窗口右区采用实色抽屉，避开标题和输入区。
- 真实模式按项目保存布局，重开恢复位置、选择、关闭状态及尺寸；Mock 模式仅当前窗口，状态栏明确标注。
- 复用真实 Pi、审批、模型/思考等级设置、流式消息和 ConPTY。页面移动或关闭不销毁终端进程，退出应用才释放。
- 消息复制、引用、用户消息带回草稿；文本选择及选区菜单；本会话查找跳转；小型文本文件引用。引用参与发送/插入，失败回填，随草稿持久化为普通文本。带引用时阻止扩展命令，避免变成命令参数。
- 侧边引用/问题可带回主会话，不产生伪造回答；会话目录可跳转到消息。
