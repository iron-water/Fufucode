# Workbench Demo 自测与重写交付

日期：2026-10-05。用户要求：先写每个区域/交互/UI 可能问题的详细自测表，自测后重写并重新打开；不要求匹配 HTML，要求应用内部风格一致。

## 验收边界

- 先建立 `docs/design/workbench-selftest-matrix.md`，共 107 个场景，再实施。
- 不把“显示一个功能页”当成“该功能全部可用”；每项注明完整/部分通过、未实现或未测。
- 主工作区 `main` 实施；无子 agent、无新 worktree；未修改第三方 reference、未推送、未改写历史。
- 既有未提交原型/调研文档与 `scripts/demo-verify/demo-verify-results.json` 保持不动，不纳入本次提交。

## 重写内容

- 单一停靠页签栏；右键移动/关闭/排序；页签控件复用、活动页签自动滚入可见区、关闭最后页收起区域。
- 默认左 232、右 320、底 240；终端默认隐藏；小于 1100 宽时侧栏自动收起，显式打开互斥抽屉。
- 使用同一 Fluent 灰阶/蓝色强调；补齐搜索与浏览器箭头图标；输入焦点样式统一，移除重复工具栏和部分说明性 UI 文字。
- 限制长项目名、修正用户消息水平无界测量；最小尺寸展开终端时空态不再盖住输入。
- 浏览器两行紧凑工具栏、页面实例停放、同帧移区保留 controller；关闭主窗口释放，异步初始化检查窗口生命周期。
- 全局浮层期间隐藏 Native WebView2，避免 airspace 遮挡。
- 终端输出行列按实际 viewport 计算；运行终端关闭确认，取消保留会话，接受只关闭选中实例。
- 侧边页统一命名为引用草稿，空态禁止无效操作，带回后清空，按会话区分草稿；未实现分叉收进更多菜单。
- Pi RPC 在写入/关闭竞态中保留错误原因和执行状态未知提示，正确观察 waiter 错误；新增并发关闭回归。
