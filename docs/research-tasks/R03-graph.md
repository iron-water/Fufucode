# R03 对话与图结合的节点控制台

遵守 [共同协议](README.md)。允许写入：仅 `docs/research-results/R03/`。

用户希望简单对话和图协同控制 agent：查看线程上下文、方便 fork、管理多个 agent。“控制”的具体语义尚未确定，不可直接实现全自动编排。

必答：
1. 区分会话、消息、分支、agent 实例、运行任务、上下文引用六类节点；哪些是 Pi 原生实体，哪些仅前端投影？
2. 用当前 Pi 版本证据解释 fork、tree/导航、上下文压缩、消息历史及可编辑边界，不把上下文显示等同于任意改写。
3. 比较只读历史图、可操作会话图、任务 DAG 三种路线，推荐最小范围。
4. 设计选节点查看来源、fork 到草稿、比较分支、将引用送入另一个 agent 的操作流程；必须有用户授权，不默认跨会话发送。
5. 定义边的含义、运行状态、父节点不变性、工具副作用提示、失败/取消、恢复、权限和信息泄露边界。
6. 图是三栏中的可停靠功能页，对话仍是主入口；说明图与窗口映射及布局保存的关系。

验收：术语表、实体/状态图、三条可验收用户流程、低保真示例（可用 Markdown 图）、未定问题及最小实施方案。不添加真实依赖或伪称运行成功。
