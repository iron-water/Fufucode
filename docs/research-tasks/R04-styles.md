# R04 保持布局的三种视觉风格探索

遵守 [共同协议](README.md)。允许写入：仅 `docs/research-results/R04/`。

用户认可当前简洁的 Fluent 倾向和三栏选择功能页的布局，希望探索现代 iOS 液态玻璃、Windows 8 纯平面、Windows 7 / 早期 iOS 拟物。当前布局、信息密度和默认外观不能改变。

研究三种风格的材质、边界、层级、图标、交互反馈及无障碍，给出对应 Avalonia 版本支持证据。区分 CSS blur 演示与真实系统合成材质。玻璃需可读性与降低透明度回退；平面不可只去掉圆角；拟物不应靠装饰压缩工作空间。
允许在结果目录制作独立 HTML/CSS 风格样张，不修改当前原型，不引入新外网依赖；使用仓库已有 lucide 和图片。必须保持三栏、中央会话、顶部/底部、相同控件集合，并提供浅/深色、1440 和 390 宽的验证证据。

验收：三套设计 token、对应同一视图的样张/截图、实现成本、可读性检查和对默认风格的兼容策略。无法运行截图时明确未验证。最终选型由用户决定。
