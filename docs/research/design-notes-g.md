# 轨道 G：品牌资产设计笔记

## 2026-09-30 自绘标题栏图标

标题栏资产采用 `titlebar/{minimize,maximize,restore,close}-{normal,hover,pressed}` 命名，每个 SVG 画布为 46×32 DIP，对应自绘 TitleBar 的一个控制按钮槽位。正常态透明，让 App 按窗口主题绘制标题栏底色；悬停与按下态使用浅青灰表面 `#E9F3F4`、`#D3E7E8`，线条用品牌深色 `#102A3A`。关闭按钮悬停/按下使用 Fluent 常见的危险操作红 `#C42B1C`、`#A4262C` 和白色叉号。普通三个符号使用现有资产线色 `#315B68`，线宽 1.35。

资产提供 1x/2x/3x PNG（46×32、92×64、138×96），便于 App 按 DPI 选择；按钮槽位尺寸只是绘制素材尺寸，不代替更大的可点击区域。SVG 都由本轨原创路径构成，只参考 Fluent/UniGetUI 的简洁线性视觉语言，不复用其资产。TitleBar 实现应按窗口状态切换 restore/maximize 图标，按 pointer enter/press/leave 展示三态；关闭按钮在悬停/按下时切换红色状态。App 仍需提供本地化 accessible name、键盘操作、足够的命中区域以及主题适配。

日期：2026-09-29。研究对象为本地只读 `reference/UniGetUI` 快照及公开的 [Codex app 介绍](https://openai.com/index/introducing-the-codex-app/)。这里只借鉴视觉组织方式，所有交付图形均重新绘制。

## 参考观察

- UniGetUI 的 `media/assets/devolutions-unigetui-icon.svg` 是 72×72 矢量源：饱满的圆角外轮廓、少量大形体、青蓝色的径向/线性渐变与浅色前景。图形核心是“多层平台＋下载箭头”，缩到小尺寸仍有明确剪影。Fufucode 不沿用该形体。
- `media/assets/splash-light.svg` 与 dark 版本按主题提供独立画面，留白占主要面积，品牌图和字标集中排列。空态借鉴“清楚的单焦点＋克制留白”，避免把插画做成页面背景。
- `UniGetUI.iss` 的 `SetupIconFile`、`WizardImageFile`、`WizardSmallImageFile` 分别消费 ICO、侧图、方图；`InstallerExtras/installer-banner.png` 实测为 330×630，`unigetui-256.png` 为 256×256。其暗色动态文件与普通文件共用。Fufucode 保留相同交付尺寸，并额外提供 SVG 源。
- Codex app 公开介绍展示的产品重心是项目/任务导航与内容审阅，界面层次安静，内容优先。借鉴这种低噪声思路：空态只给轻量图形，不叠加长段说明、装饰线框或假按钮。此项是对公开页面的视觉判断，并非引用其品牌资产。

## Fufucode 方案

- **图标构图**：深海蓝圆角方形容器内，一条暖白色的“代码光标”折线和青蓝弧形对话尾形成独立轮廓。识别关键词为“对话中的代码”，避开 UniGetUI 的层叠下载符号，也避开 Codex 标志。16/24 px 版减少细节，只保留大笔画。
- **色板**：深底 `#102A3A`、中青 `#087F99`、亮青 `#47D9DA`、暖白 `#F7FAF8`；空态浅色用 `#E9F3F4` 面色和 `#315B68` 线，深色用 `#173743` 面色和 `#9CDDE0` 线。渐变只用于品牌主形，功能状态依靠形状和文案区分。
- **空态**：三幅同一语言的轻量线面插画，分别表达“开始对话”“扩展接入”“连接中断”。透明背景，画面 320×200；在浅/深主题分别导出 1x 与 2x PNG。插画中心占 60% 左右，四周保留界面正文和操作空间。
- **安装器**：330×630 侧图承载图标与低对比背景弧线；256×256 小图供向导横幅；完成页用 256×256 单焦点勾选图。避免在图片内写死中文/英文文案，由安装器本地化层呈现。
- **小尺寸**：独立 `icon-small.svg` 调整笔画与间距，嵌入 ICO 的 16/24/32 层；窗口与任务栏可直接使用同一图像，不做字标。

## 原创与消费边界

所有 SVG 由本轨用代码绘制，PNG/ICO 由 CairoSVG 与 Pillow 从 SVG 渲染；未包含第三方路径、商标、字形、照片或 AI 图像生成素材。设计工具为 Codex 编写的 SVG 生成脚本；提示词要点是“Fluent 桌面质感、青蓝渐变、代码对话语义、可缩放、原创构图”。图形文件交轨道 D 接 Avalonia，安装器文件交轨道 F 接 Inno Setup。

## 2026-09-30：会话标题栏动作图标

本轮按 D 轨已收敛的会话标题栏功能补一组独立动作符号：新建会话、展开、收起、暂停、继续、停止，以及窗口最小化、最大化、还原、关闭。图形采用 24×24 viewBox、无填充的圆角描边和统一的 1.8 px 线宽；16/20 px 导出保留关键轮廓，适配紧凑标题栏。图标使用中性深青色 `#315B68`，浅/深主题状态色、悬停/禁用状态由控件按主题提供，避免同一资产复制两套主题版本。

新建会话以对话框轮廓加号表达；展开/收起用四角朝外/朝内的箭头表达；运行控制采用标准双竖线、播放三角和方形；窗口控制采用底边短线、单框、叠框和交叉线。图标仅表达动作，不含文字；调用方须提供本地化可访问名称，运行控制也须按实际会话状态切换暂停/继续图标并区分停止行为。全部 SVG 由 `assets/generate.py` 的原始路径绘制，PNG 是同源光栅导出；没有复用 UniGetUI 图形。
