# 皮肤意见的派工输入快照

来源：用户未跟踪文件 `docs/人类意见/前端风格.md`，2026-10-13主控准备时只读摘录；不暂存或改写原文件。修订源仍以用户意见为准。

- Fluent 2：当前基础，参考UniGetUI、GestureSignV2和Windows11设置。
- Metro：Windows8视觉理念，先几个样稿供用户定夺。
- Aero：尤其推崇Vista视觉，Avalonia能否实现需要实际验证。
- Luna：XP风格，多状态资产较多，后续另做。
- Material3：已有完整规范，原始候选之一。
- Liquid Glass：当前明确暂缓。

本线程补充：用户希望额度有限的Opus5.5担当设计教师，留下完整可参考的视觉形象和参考书；过粗其他模型无法照做，过细纯写文不划算。采用“有限关键样板亲手实现＋token/状态表＋迁移示范＋可直接执行prompt”，普通实现交低成本模型。现最新用户要求皮肤前提并派发任务，不等其他功能全部完成。

产品不变量：功能/五区布局对齐当前Fufucode与Codex思路，默认审美Fluent/UniGetUI；独立Windows设置页布局/左右辅助栏基线不推翻。页签和整辅助栏可浮动，取消旧独立浮窗，通知/用量在通用功能页；三渠道提醒保留。主页面最底部极扁状态栏默认关闭，状态栏开关不等于底部终端。

有已接受S1 Fluent/Metro/M3 HTML和18帧，复用，不重做原模块。新皮肤可选实现和机制可以前提；新增默认皮肤/视觉终验仍需用户选择。Aero教师样板现在允许有限探索，正式Aero生产接线仍分阶段，不声称已完成。HTML/AXAML示意/真实编译控件/系统原生效果各自明示证据边界。
