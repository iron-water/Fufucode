# 任务书一：补齐现有能力的管理界面

日期：2026-10-10。状态：未开始。本文是新增开发范围，不是实现或验收报告。

## 使命与基线

把现有快捷键、存储、Git/工作树和浏览器能力整理成可发现、可配置、可诊断的界面。复用现有五区外壳、Windows 设置式导航与左右辅助栏，不复制业务状态。源码基线来自本轮静态核对；开工时只复核相关文件，不沿用历史验证作为新改动的通过证明。

本任务不包含浏览器 Agent 自动操作、完整 Git 客户端、云端账户计费或通用密码管理器。浏览器 Agent 能力作为后续增量，见总排期。

## M1 快捷键管理

- 从实际动作注册表生成可搜索列表，显示作用范围、当前绑定与不可用原因。
- 支持修改、禁用、逐项恢复默认、全部恢复默认及持久化。
- 区分全局、聊天、浏览器、终端上下文；冲突必须展示双方动作，不静默覆盖。
- 明确保留键及组合键规则。中文输入法组合期间不误触发送；终端输入优先级不能被全局快捷键抢走。
- 保守默认：沿用现有绑定，配置损坏时回退默认并报告，不覆盖损坏文件。

验收：修改后立即生效、重启保留；冲突能解释并解决；焦点不同产生正确动作；中文组合输入正常；禁用和恢复可逆。必须做原生键盘行为验证，动作回调测试不能替代。

## M2 存储与数据管理

- 展示应用数据、运行时、会话、日志、缓存、导出和浏览器数据目录及实际占用；计量可取消，不阻塞输入。
- 提供打开目录、保留策略和明确范围的清理；预览实际目标及预计大小，结束记录实际结果。
- 默认仅清理可重建缓存和过期日志；会话、配置、认证、资料、项目源码及工作树不纳入自动清理。
- 活跃写入数据不可直接移动。第一阶段不做任意数据根迁移；后续若做，需停写、复制校验、失败恢复及重新启动验证。
- 浏览器数据清理明确提示登录状态影响；不把模型认证与浏览器 cookies 混合管理。

验收：真实大小与计量口径一致；指定缓存能清理，活跃文件失败不损坏其余数据；用户源码/会话/凭据保持不变；取消有效；清理前后占用变化有证据。

## M3 Git 与工作树管理

- 提供仓库状态、分支、已暂存/未暂存/未跟踪分类与差异入口；如实保留用户原有变更归属。
- 第一阶段增加明确目标的暂存、取消暂存及提交；提交先展示包含文件，不默认选全仓。
- 工作树列表以 Git 实际列表为准，显示路径、分支、关联聊天、占用和脏状态。
- 工作树创建复用现有实现；移除先检查活跃会话、未提交与未跟踪内容，默认拒绝脏目录或被占用目录。
- 使用 git worktree remove，不直接递归删除；不实现默认强删、强推或改写历史。
- 后续再评估拉取、推送、冲突解决与恢复；网络失败不伪装成功。

验收：在临时仓库实际验证选择性暂存/提交、中文路径、脏工作树保护和干净工作树移除；失败后用户改动保留；关联会话路径有效。不得对用户日常仓库做破坏性试验。

## M4 浏览器管理与基础体验

- 增加多标签、查找、缩放、历史检索、下载列表与取消/重试、弹窗目标处理及设置入口。
- 下载路径使用 Windows 已知文件夹或用户选择，不拼接 UserProfile/Downloads；当前源码中此处存在已迁移下载目录不匹配风险。
- 浏览器配置与历史使用应用独立 profile；网站权限按来源管理，提供撤销与清理。
- 加载、错误、WebView2 缺失、恢复标签、关闭标签及资源释放均有可见结果。
- 验证原生 WebView2 的焦点、DPI、停靠/浮动/隐藏、窗口覆盖及快捷键；保留文件预览独立能力。

验收：本地测试网站验证历史/多标签、弹窗、下载成功/取消/同名文件、权限拒绝、找文本与缩放；迁移后的 Downloads 正确；关闭标签无活动宿主残留；原生输入与高DPI行为通过。

## 实施与交付

主要入口：SettingsPageViewModel、SettingsPage、MainWindow.Actions、WorkbenchActionDefaults、BrowserView/BrowserViewHost、工作区变更页及 Core 工作树实现。具体所有权开工时按真实文件确定。

逐项提交代码与 docs/progress.md、docs/decisions.md、验证记录；缺陷进入 docs/records/failure-registry.md。不新增虚假入口，不靠删除功能或放宽断言完成验收。

共享动作、存储和原生宿主改动由主 agent 实施；独立设置子页可派受限任务包，同一文件不并行。测试/试跑显式选最低成本可用模型，首选 devin/swe-2；不以默认强模型执行。普通构建与无模型测试不需要模型参数。

本任务完成条件：M1–M4对应行为实测通过，必要构建零警告/错误，涉及范围的测试通过，配置重启恢复及发布布局验证通过，记录明确尚未执行的项。无需为纯文案修改反复全仓回归。
