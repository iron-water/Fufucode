# 任务书三：手机远控、资料库与图像生成

日期：2026-10-10。状态：未开始。本文定义新能力，未授权公开部署、付费采购或账号操作。

## N1 手机远程控制

目标：手机操作本机 Fufucode 会话，桌面和手机共享任务与审批状态。视觉参考 C:/Downloads/WorkBuddy.apk.1；当前仅静态确认Flutter资源，正式设计前需实际查看页面与交互，不凭素材猜界面。

阶段一：响应式Web/PWA原型，包含设备连接、项目/会话列表、流式聊天、工具卡片、发送、停止、审批、附件及断线提示。适配窄屏、键盘弹出、长消息、返回路径与安全区。以实际任务使用为验收，不复制桌面五区布局到小屏。

阶段二：本地配对和局域网连接。任务宿主是唯一会话写入者；桌面窗口与手机作为客户端。设备可命名、查看、撤销，短期配对码有期限；访问须认证，不把Pi/OMP原始管道暴露到网络。

- 命令带稳定身份，重试可去重；事件可按游标补齐，重连恢复当前快照和审批有效性。
- 审批绑定具体会话、调用及参数；旧审批不继续有效。手机与桌面同时操作时显示真实竞争结果。
- 电脑睡眠、桌面退出、后台宿主退出分别明确展示；不承诺电脑关机后继续执行。
- 第一阶段远控仅限会话，不包含整个桌面、浏览器画面或终端键盘转发。

阶段三：外网通路。先评估已有用户可用的私有网络/连接方案；公网中继另列运维、费用和部署任务，不隐式采购。增加连接加密、设备会话撤销、限流与最小诊断；测试不能打印token。

验收：真实手机完成任务发送、流式查看、审批、停止；锁屏/切网/重连后不重复任务、不错过终态；设备撤销后不能控制；桌面手机状态一致；无网络和宿主退出有明确提示。真实外网及推送需分别验证，局域网成功不算通过。

## N2 资料库

目标：用户可收藏本地文件、网页资料、会话片段和产物，跨会话检索与明确引用。区别于文件树和完整聊天历史。

阶段一：资料条目、分类/标签、标题、来源、收藏时间、搜索、预览、导入/导出和删除。首版以本地文本/Markdown/常见文档为主；文件保存“引用”或“副本”必须让用户看懂。来源不可达或变化标记失效，不能冒充原内容。

阶段二：全文索引与聊天引用。显示引用片段、原始来源与版本；发送前可选择内容，不自动将整个资料库送给模型。格式提取失败保留原文件并显示原因，扫描PDF等OCR另列能力。

阶段三：再评估向量检索/OCR/跨设备同步。首版不要求云同步或付费嵌入，全文检索足够时不增加服务依赖。

验收：中文路径/同名文件、重复导入、源移动/删除、内容变化、索引重建、批量导出均正确；删除条目默认不删除引用的用户源文件；引用可回溯到真实内容；敏感资料未选中不传出；大资料索引不阻塞输入。

## N3 图像生成与编辑

目标：独立图像工作流，包含提供商/模型选择、提示词、参考图、可用参数、生成任务、编辑、取消、下载和历史。现有图片附件输入不计为该模块实现。

阶段一：先接一种真实支持的提供商，能力表按实测呈现；生成/编辑/透明背景/尺寸等不支持时禁用并解释。图像服务通过独立适配接入，不假设Pi/OMP模型拥有相同能力。

阶段二：本地生成历史和资料库收藏，保存模型、参数、提示词、来源及原图；失败或中断可诊断。编辑生成新版本，不覆盖用户原图。交付进聊天及项目须显示实际路径。

- 每次收费请求展示可获得的费用信息与未知项；提交边界有明确身份，不盲目重试导致重复收费。
- 取消区分本地停止等待与服务端取消确认；服务器结果未知时标未知，不声称没有计费。
- 参考图提交需用户选择；认证存储与诊断遵循现有安全边界。
- 批量生成、图库云同步、模型市场与自动生图供Agent使用作为后续增量。

验收：真实生成与编辑各一次，产物能打开/下载/收藏；失败、限额、断网、取消、重启后状态如实；原图不改；请求与费用边界可追踪。试跑显式选最便宜且支持目标能力的图像模型；免费文本模型不能冒充图像验收，付费/强模型需求先说明并获得授权。

## 依赖、分工与交付

手机依赖公共会话宿主和后台生命周期；资料库可独立先做；图像历史复用资料条目与产物存储。认证/外网/公共宿主由主 agent 实施；手机原型、资料列表和图像历史可独立派受限任务包，不同任务不同时修改共享接口。

每阶段提交可运行入口、必要行为证据和记录。新页面默认诚实空状态，不塞演示资料冒充真实历史。用户不在场时按本文保守默认推进；登录、付费或产品方向阻塞登记并继续其他阶段。
