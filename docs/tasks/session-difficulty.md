# 会话难度与派工提示

日期：2026-10-10。供M派工与用户选择会话主模型使用；是基于任务范围的预估，不是实测工期、模型基准成绩或费用承诺。难度真源在本文件，人类图表同步展示。

## 标签

| 标签 | 含义 | 会话主模型建议 |
| --- | --- | --- |
| L1 轻量 | 明确机械改动、格式/文案；无公共契约变化 | 最低成本可用模型 |
| L2 常规 | 边界清楚的独立模块；实现路径成熟 | 先选免费/低成本实现模型，必要时A/B档 |
| L3 较难 | 多状态、多文件、原生行为或契约接线 | A档起步；复杂判断可由S档做窄范围审查 |
| L4 很难 | 跨后端/进程/安全边界/恢复，失败影响多个模块 | S档会话主模型负责设计与关键实现；拆给低成本执行者 |

模型S/A/B/C档按用户当前canonical AGENTS模型分级与实际目录判断；L1-L4是任务难度，不是模型等级。免费devin/swe-2在用户分级中属A档，不能把价格直接当智力。用户酌情选择，本协议不自动换模型、不默认最高价。工具需求、实施量、外部阻塞另外说明，不能把“要computer-use”简单等同L4。未知接口、扩大范围或新故障可调整难度，必须说明事实和原因。

## M每次派工必须主动提示

新增 U 任务：U0 研究/交互原型 L3；U1 持久任务/投递/单写入规则 L4；U2 独立宿主/跨 harness 恢复 L4；U3 原生任务队列界面 L3。具体范围、依赖与建议模型见 [自动开发工作台](automation-workbench.md)，测试模型纪律不变。

新派任务推荐主模型及备选必须从用户当前canonical目录的`group/`条目选择，明确写完整ID，不只写档位、简称或“低成本”。完整prompt首行格式：`任务：<ID>｜难度：Lx｜推荐主模型：group/<完整路由名>｜理由：<具体依据>`。按任务综合判断，例如常规模块可选`group/auto-deepseek-v4-1-flash`，复杂跨边界设计可选`group/auto-gpt-6-1-sol`，不按例子固定派单。此要求只约束新派主模型建议，不改变打回保留原模型与测试首选免费`devin/swe-2`的纪律。

新派任务（包括新增/拆分任务）综合评估范围、状态复杂度、接口依赖、失败影响和工具需求，给出任务ID、L标签、具体理由、推荐模型ID及备选、依赖、worktree与完整prompt。模型建议基于当前canonical目录与成本，不只给笼统档位；用户选择，不自动切换。完整prompt首行必须含任务ID和难度，复制后仍保留。

打回修复默认复用原会话、原工作树、原主模型，不推荐换lead。prompt首行写原始派工等级、当前修复等级与升级差值；以原始等级为基线，不逐轮滚动抬高，也不按打回次数推定难度。只有当前难度比原始派工升高至少两级时，才提示可使用更强子代理辅助限定修复，并说明独立范围、推荐模型和工具兼容。这是可选建议，不自动派发、不要求换lead或新建会话；升级不足两级时不提示升级模型/子代理。

例如O2原L2→修复L3（+1）：保留原模型；L2→L4（+2）或L1→L3（+2）：可建议更强实现子代理。原负责人负责整合复核，禁止同文件并行写入。测试、验证、试跑仍最低成本；升级实现子代理不允许变成昂贵测试lead。

示例：D1｜L4很难｜后端协议与恢复跨模块｜建议S档设计/主实现｜需原生UI验证｜Codex Worktree；O1｜L2常规｜独立动作配置模块｜免费/低成本模型优先｜主会话接线后原生验收｜OMP独立工作树。

模型示例从当前已配置/可用目录取，不把榜单存在当作本会话可调用成功。第三方路由、认证及密封兼容未知时说明未知；不为选模型擅自收费试跑。

**成本硬约束**：测试、验证、试跑始终显式用最低成本可用模型；L4不允许默认用强模型做测试lead。S档定位复杂缺陷与跑测试是不同工作；确需强模型验证须理由、预算与用户同意。普通无模型编译不涉及模型参数。

## 子代理与执行会话

用户新建的Codex/OMP对话不是原生子代理。spawn子代理不自动创建独立工作树，父子共享代码目录时必须划清文件；源码并行仍按隔离/所有权规则。仅在已有授权和适合的独立子任务下派发，核心跨文件改动保持负责人持有。

按用户指定的C:/AI/Harness/Codex/knowledge/codex-提示词与子代理信息流.md，GPT原生v2与group路由存在任务密封差异。当前工具支持模型参数不代表任意第三方能成功接收任务，配置模型不等于实际本轮模型，目录条目不等于运行验收。选模型前核对会话能力；不擅自切全局配置规避限制。不符合原生子代理条件时，可在已授权范围内用外部OMP明确模型与任务包执行，单独管理上下文、凭据、日志和退出状态，不冒称原生子代理。
