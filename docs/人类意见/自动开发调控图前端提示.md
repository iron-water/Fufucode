# 自动开发调控图：前端修改提示

日期：2026-10-11。来源：用户最新要求。当前HTML已实现视图切换和精简；原生产品验收另行记录。

最新补充优先：默认“阶段总览”，按大的开发进度显示阶段卡，点击进入二级线程依赖图，再点击节点显示详情。另可选择“完整拓扑”“仅运行中”；自由缩放作为辅助视图。完整拓扑保持全层级并适应视口，不能靠隐藏节点伪装完整显示。

## 1. 默认完整展开，一屏查看

选择完整拓扑时展开全部层级，自动适应当前可用区域，无需上下滚动即可查看完整拓扑。保留线程节点、线程内任务和部分交付的层级，不通过隐藏节点实现“一屏显示”。

增加一个“视图”选择控件：

- 阶段总览：默认选项，点击阶段进入二级图。
- 完整拓扑：全部展开并适应视口。
- 仅运行中：只显示实际运行中的执行节点。
- 自由：允许用户手动缩放和平移。

窗口大小变化时，全图模式自动重新适应。全图缩小时不强塞全部说明文字；节点保留身份和关键状态，点击后展示任务及证据。原有“显示/隐藏未运行流程”作为独立筛选保留，默认显示全部。

验收：初次打开及调整窗口后，默认可看到完整拓扑，无纵向页面滚动；视图控件可以切换模式；节点和依赖没有被裁掉。

## 2. 移除冗余，保持最高简洁性

图是主要界面。删除重复标题、重复状态、无助于操作的说明、装饰性统计和重复操作入口，不再在图之外堆放仪表盘。

默认只保留图、自动/手动模式、视图选择、未运行流程筛选和运行/暂停控制。模型、拓扑修改、撤销、重建、交付、审核、日志与证据放到选中节点的上下文中，按需展开。

正常状态简短显示；失败、阻塞及待处理操作必须明确可见。精简不能隐藏关键异常、混淆演示与真实运行，或删除已有能力。

验收：同一信息和操作只有一个主入口；默认页面没有重复面板和长篇说明；高级能力仍可从相关节点进入。
